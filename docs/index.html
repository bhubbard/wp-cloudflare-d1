WP Cloudflare D1 — Query Serverless Cloudflare D1 SQLite Directly from WordPress

Modern PHP and WordPress client library for querying Cloudflare D1 serverless SQLite databases at the network edge — featuring parameterized prepared statements, atomic batch execution, and transient caching.

      PHP (WP Cloudflare D1 Client)
      
$d1 = new \BHubbard\CloudflareD1\Client(
    account_id:  defined( 'CF_ACCOUNT_ID' ) ? CF_ACCOUNT_ID : '',
    database_id: defined( 'CF_D1_DATABASE_ID' ) ? CF_D1_DATABASE_ID : '',
    api_token:   defined( 'CF_API_TOKEN' ) ? CF_API_TOKEN : ''
);

$result = $d1->query(
    'SELECT id, event_type, created_at FROM edge_audit_log WHERE site_id = ? AND severity = ? LIMIT 25',
    [ get_current_blog_id(), 'critical' ]
);
